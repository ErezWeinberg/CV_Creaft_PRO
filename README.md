## 🌟 Key Features

* 🌐 **Full Bilingual Support (RTL & LTR):** Toggle seamlessly between Hebrew (RTL) and English (LTR) with custom typesetting and typography.
* 🎨 **4 Professional ATS Templates:**
  * **Modern Tech (Recommended):** 2-column header with dynamic accent bars.
  * **ATS Classic:** Clean 1-column single page structure optimized 100% for automated resume parsers.
  * **Minimalist Executive:** Elegant serif typography and generous whitespace for senior roles.
  * **Creative Accent:** Bold headers and tag badges for skills.
* ⚡ **Live Side-by-Side Preview & Zoom:** Real-time rendering on an exact A4 printable canvas.
* 🖨️ **Pixel-Perfect PDF Export:** Dedicated `@media print` CSS stylesheet ensures crisp, margin-perfect PDF output without UI clutter.
* 🔒 **100% Local-First Privacy:** All user data stays in browser `localStorage`. Zero server tracking, zero login required.
* 💾 **JSON Import / Export:** Save backup files locally and reload resume data anytime.
* 💡 **Sample Tech Data Included:** Pre-filled high quality English & Hebrew tech resume samples loaded with one click.
* 🎛️ **Custom Design System:** Accent color picker, font selector (*Heebo, Inter, Rubik, Merriweather*), font size scaling, and line spacing adjustments.

## 🛠️ Local Setup & Running

No Node.js build steps or complex dependencies required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/cv-generator.git
   cd cv-generator
   ```

2. **Open in browser:**
   Simply open `index.html` directly in your browser or run a simple local HTTP server:
   ```bash
   # Using Python 3
   python -m http.server 5173
   ```

3. Navigate to `http://localhost:5173` in your browser.
